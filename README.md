# Flight Booking System

A web-based flight booking application developed using Java and Spring Boot. The project demonstrates backend development, database integration, and server-side web development.

## Technologies Used

* Java 21
* Spring Boot 3.5.0
* Spring Data JPA
* Hibernate
* MySQL
* Thymeleaf
* Maven

## Features

* Web-based user interface for flight booking.
* Database integration using MySQL.
* Data persistence with Spring Data JPA and Hibernate.
* Server-side page rendering with Thymeleaf.
* Role-based functionality for passengers and administrators.

## Project Structure

The project follows a standard Maven and Spring Boot structure.

* `src/main/java` — Java source code.
* `src/main/resources` — Application resources and configuration.
* `pom.xml` — Maven dependencies and project configuration.

## Getting Started

### Prerequisites

* Java 21
* Maven
* MySQL Server

### Setup

1. Clone or download this repository.
2. Create a MySQL database for the application.
3. Configure your local database connection in `application.properties`.
4. Run the application from Eclipse or using Maven.
